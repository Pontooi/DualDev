# DualDev — Academia de Programação

O **DualDev** é uma plataforma educacional interativa desenvolvida para facilitar o aprendizado prático de desenvolvimento de software e linguagens de programação diretamente pelo navegador, sem necessidade de instalações ou configurações complexas.

---

## 🎯 Objetivo

Eliminar as barreiras iniciais que estudantes e iniciantes enfrentam ao aprender a programar, oferecendo um ambiente ágil, intuitivo e com validação imediata dos códigos digitados.

---

## 📚 Trilhas de Aprendizagem

A plataforma conta com **5 trilhas práticas** com **20 atividades interativas em cada** (totalizando **100 exercícios práticos**):

1. **Java:** Fundamentos, métodos, estruturas de repetição, arrays e manipulação de classes.
2. **Python:** Sintaxe limpa, listas, funções, condicionais e estruturas de dados.
3. **JavaScript:** Tipos primitivos, funções modernas, arrays e manipulação de objetos.
4. **HTML5:** Estruturação semântica, cabeçalhos, formulários, tabelas e acessibilidade.
5. **CSS3:** Estilização de elementos, Box Model, Flexbox, CSS Grid e transições.

---
